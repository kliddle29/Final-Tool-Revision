# Observation Protocol

Fill this in *during* the actual test session, in real time. Don't
guide the tester unless they're completely stuck, and encourage them
to think out loud.

## Before the session

- Tester: my dad, 57. Some familiarity with tech generally; very
  comfortable using a computer, no hesitation navigating one.
- Scenario given: download-and-install-to-first-use (see
  `testing-scenario.md`), no explanation beyond the link
- Link given: the standalone app download from the GitHub Release
- Date/time: _______________

## During the session (observe silently, take notes)

- Where did they hesitate?
- Where did they misunderstand the interface?
- Where did they try something unexpected?
- Where did they succeed immediately, without help?
- Anything they said out loud worth quoting directly?

## Optional: interaction logging

If logging was added to the app (see `main.js`/`renderer/lens.js` for
a toggle-count / active-duration counter), note what it showed here
after the session.

- Anything the tester said *after* finishing the form that didn't fit
  into a form answer: _______________
